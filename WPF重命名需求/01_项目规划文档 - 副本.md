# WPF TreeView 右键重命名功能 - 项目规划文档

## 📌 项目概述

**项目名称：** TreeViewRenameDemo  
**开发模式：** WPF + MVVM  
**开发语言：** C# (.NET Framework 4.7.2 或 .NET 6.0)  
**UI框架：** WPF  
**架构模式：** MVVM (Model-View-ViewModel)  
**依赖库：** 
- Prism.Wpf（用于 Command 和依赖注入）
- Microsoft.Xaml.Behaviors.Wpf（用于交互行为）

---

## 🎯 需求分析

### 功能需求

#### 1. 基础树形展示
- 显示多层级树形结构
- 支持节点展开/收起
- 自定义节点图标
- 节点选中高亮效果

#### 2. 右键菜单功能 ⭐核心需求
- 右键节点弹出 ContextMenu
- 菜单项包含：
  - 重命名
  - (可扩展：删除、新增子节点等)

#### 3. 重命名功能 ⭐核心需求
- 点击"重命名"后，节点文本变为可编辑状态
- TextBlock 切换为 TextBox
- 支持 Enter 键确认、Esc 键取消
- 失去焦点时自动保存
- 验证输入不为空

#### 4. 数据绑定
- 使用 ObservableCollection 实现数据双向绑定
- 修改后数据自动同步到 ViewModel
- 支持嵌套子节点

## 📐 详细设计

### 1. Model 层设计

#### TreeNode 类
```csharp
属性：
- string Name                  // 节点名称
- string Icon                  // 图标路径（Path Data）
- bool IsExpanded              // 是否展开
- bool IsSelected              // 是否选中
- bool IsEditing               // 是否处于编辑状态 ⭐新增
- string ToolTip               // 工具提示
- ObservableCollection<TreeNode> Children  // 子节点集合

事件：
- PropertyChanged              // 属性变更通知
```

---

### 2. ViewModel 层设计

#### MainViewModel 类
```csharp
属性：
- ObservableCollection<TreeNode> TreeNodes  // 根节点集合
- TreeNode SelectedNode                     // 当前选中节点

命令：
- ICommand RenameCommand                    // 重命名命令
- ICommand ConfirmRenameCommand             // 确认重命名命令
- ICommand CancelRenameCommand              // 取消重命名命令

方法：
- void StartRename(TreeNode node)           // 开始重命名
- void ConfirmRename(TreeNode node)         // 确认重命名
- void CancelRename(TreeNode node)          // 取消重命名
- void InitializeTreeData()                 // 初始化树数据
```

---

### 3. View 层设计

#### MainWindow.xaml 结构

**核心元素：**

1. **TreeView 控件**
   - ItemsSource 绑定到 TreeNodes
   - 自定义 ItemContainerStyle
   - 自定义 HierarchicalDataTemplate

2. **ContextMenu（右键菜单）**
   ```xaml
   <ContextMenu>
       <MenuItem Header="重命名" Command="{Binding RenameCommand}" />
   </ContextMenu>
   ```

3. **节点内容模板（关键）**
   ```xaml
   <HierarchicalDataTemplate DataType="{x:Type TreeNode}">
       <StackPanel Orientation="Horizontal">
           <Path Data="{Binding Icon}" />
           
           <!-- 正常显示模式 -->
           <TextBlock Text="{Binding Name}" 
                      Visibility="{Binding IsEditing, Converter={...}}" />
           
           <!-- 编辑模式 -->
           <TextBox Text="{Binding Name, UpdateSourceTrigger=PropertyChanged}" 
                    Visibility="{Binding IsEditing, Converter={...}}"
                    KeyDown="OnTextBoxKeyDown"
                    LostFocus="OnTextBoxLostFocus" />
       </StackPanel>
   </HierarchicalDataTemplate>
   ```

### 4. 交互流程设计

#### 重命名操作流程

```
用户操作                    系统响应
   │
   ├─ 右键点击节点 ──────→ 弹出 ContextMenu
   │
   ├─ 点击"重命名" ──────→ 执行 RenameCommand
   │                       └─ 设置 IsEditing = true
   │                       └─ TextBox 获取焦点
   │
   ├─ 输入新名称 ────────→ 双向绑定更新 Name 属性
   │
   ├─ 按 Enter 键 ───────→ 执行 ConfirmRenameCommand
   │                       └─ 验证输入
   │                       └─ 设置 IsEditing = false
   │                       └─ 保存新名称
   │
   ├─ 按 Esc 键 ─────────→ 执行 CancelRenameCommand
   │                       └─ 恢复原名称
   │                       └─ 设置 IsEditing = false
   │
   └─ 失去焦点 ──────────→ 自动确认（或取消）
```

## 🔧 技术实现要点

### 1. 数据绑定
```csharp
// TreeNode 必须实现 INotifyPropertyChanged
public class TreeNode : INotifyPropertyChanged
{
    private bool _isEditing;
    public bool IsEditing
    {
        get => _isEditing;
        set
        {
            _isEditing = value;
            OnPropertyChanged(nameof(IsEditing));
        }
    }
}
```

### 2. Command 绑定
```xaml
<!-- 方式1：通过 ViewModel 的 DataContext -->
<MenuItem Header="重命名" 
          Command="{Binding DataContext.RenameCommand, 
                    RelativeSource={RelativeSource AncestorType=TreeView}}"
          CommandParameter="{Binding}" />
```

### 3. 转换器
```csharp
// BoolToVisibilityConverter
public class BoolToVisibilityConverter : IValueConverter
{
    public object Convert(object value, ...)
    {
        return (bool)value ? Visibility.Visible : Visibility.Collapsed;
    }
}

// InverseBoolToVisibilityConverter（取反）
```

### 4. 焦点管理
```csharp
// TextBox 获取焦点并全选文本
textBox.Focus();
textBox.SelectAll();
```

## 📝 开发规范

### 命名规范
- 类名：PascalCase（如：TreeNode）
- 属性：PascalCase（如：IsEditing）
- 私有字段：_camelCase（如：_isEditing）
- 方法：PascalCase（如：StartRename）
- 事件处理：On + EventName（如：OnTextBoxKeyDown）

### 注释规范
- 所有 public 类和方法必须有 XML 注释
- 复杂逻辑必须有行内注释
- 注释使用中文

### 代码规范
- 遵循 C# 官方编码规范
- 使用 MVVM 严格分离 View 和 ViewModel
- 避免在 ViewModel 中引用 WPF 控件
- 使用依赖注入
