## 第二章 协议要点（依据 docx 原文）

### 帧格式

```
| 字节0 | 字节1 | 字节2-3 | 字节4-5 | 字节6~N | (N+1)-(N+2) |
|  SOF  |  FUNC |  CMD    | DATALEN |  DATA   |    CRC      |
| 0x01  | 0x06  | 大端2B  | 小端2B  | 变长    | 小端2B      |
```

- CRC16/Modbus：多项式 0xA001，初值 0xFFFF，输出小端
- CRC 范围：SOF → DATA

### 五条指令

| 指令 | CMD | 发送 DATA | 回复 DATA[0] |
|------|-----|-----------|-------------|
| UPGRADE_REQ | 0x0010 | [0x01请求/0x02查状态, 0x00] | 0x00=Boot就绪 / 0x01=跳转中 / 0x02=App仅回 / 0x03=Boot仅回 |
| UPGRADE_START | 0x0011 | [文件大小 uint32 小端] | 0x00=擦除完成 / 0x01=失败 |
| UPGRADE_DATA | 0x0012 | [偏移 uint32 小端 + 数据≤128B] | 0x00=完成 / 0x01=失败 |
| JUMP_APP | 0x0013 | [0x01] | 0x00=成功 / 0x01=失败 |
| VER_REQ | 0x0014 | [0x01] | 5 字节版本号 |

### 升级四步时序

```
请求(0x0010)→Boot就绪 → 启动(0x0011,大小)→擦除完成
→ 循环发数据(0x0012,每帧≤128B,等确认) → 完成(0x0013)→跳转App
```

### 串口默认

**115200 / 8位 / EVEN / 1停止**（取自官方 ConfigInfo.ini）；通讯超时 5s，擦除超时 30s，重试 3 次。

## 第四章 学习交付规划（目标②）—— ★ 核心新增 ★

### 4.1 学习策略：WPF 对照学习法

> **一句话**：每一个 Qt 知识点，先用"这是 WPF 里的 XX"建立锚点，再讲 Qt 的原理与差异。

这是为"熟悉 WPF、初学 Qt"的你定制的最高效路径——把学习成本从"学一门新语言"降为"学一套新语法与机制"。

### 4.2 WPF → Qt 概念总对照表（先行预览）

| 你在 WPF 中已掌握 | Qt 中的对应物 | 机制本质差异 |
|--------------------|---------------|--------------|
| `.csproj` / `.sln` / MSBuild | `.pro` / qmake | 声明式 vs 文本脚本；MOC 预编译 |
| XAML | 手写布局代码 / Qt Designer .ui | 标记语言 vs 代码（Qt 亦可 .ui 文件） |
| `INotifyPropertyChanged` | `Q_PROPERTY` + 属性变更信号 | 接口 vs 元对象宏 |
| `event` / delegate | **信号槽 signals/slots** | 编译期绑定 vs 运行期 MOC 解析 |
| `ICommand` / RelayCommand | 槽函数 + 按钮 `clicked` 信号 | 接口 vs 函数指针连接 |
| Binding + Converter | `QDataWidgetMapper` / 槽更新 / delegate | 声明式 vs 命令式 |
| `ObservableCollection<T>` | `QAbstractListModel` + dataChanged 信号 | 集合通知 vs 模型视图架构 |
| DataTemplate | `QStyledItemDelegate` / `paint()` | XAML 模板 vs 绘制代码 |
| `Dispatcher.Invoke` | `QMetaObject::invokeMethod` / QueuedConnection | 线程封送机制相同思想 |
| `async/await` | 状态机 + 信号推进 / QtConcurrent | 语言级协程 vs 事件驱动 |
| Style / Template / Trigger | **QSS 样式表** | XAML 对象树 vs CSS 类语法 |
| Grid / StackPanel / DockPanel | QGridLayout / QVBoxLayout / QHBoxLayout | 布局系统，语义相近 |
| RoutedEvent 隧道/冒泡 | `event()` 重写 / `installEventFilter` | 路由 vs 责任链 |
| GC 自动回收 | 父子对象树 + deleteLater | 引用追踪 vs 树所有权 |
| `System.IO.Ports` | `QSerialPort` | 事件驱动、API 更贴近硬件 |
| `Debug.WriteLine` | `qDebug()` 日志分类 | 输出机制 + 格式串 |
| NuGet | 编译时 `QT += module` | 包管理 vs 静态模块选择 |
| `dotnet publish` 发布 | `windeployqt` 部署 | 单文件 vs DLL 收集 |

> 这张表就是学习指南的骨架，后续每个专题围绕它展开。

### 4.4 教学型代码注释规范

> 与"功能注释"不同，教学注释还回答"为什么 Qt 要这么设计"。

```cpp
// 【Qt知识点】信号槽连接的线程语义：
// 默认 AutoConnection —— 发送者与接收者同线程则直接调用（同步），
// 跨线程则自动转为 QueuedConnection（投递到接收者事件循环，异步）。
// 对比 WPF：同线程等价于直接 Invoke，跨线程等价于 Dispatcher.Invoke。
```
