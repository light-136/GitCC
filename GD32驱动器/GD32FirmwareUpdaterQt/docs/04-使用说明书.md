# GD32 低压驱动器固件升级工具（Qt版）— 使用说明书

> 版本：1.0.0 | 日期：2026-08-14
> 工具链：Qt 5.12.2 (MinGW 7.3.0 64bit) | 源码配套参考：`docs/02-详细设计文档.md`

---

## 一、软件简介

本软件用于对 **GD32 低压驱动器** 进行 Boot 固件升级，通过串口与设备内的 Boot 程序通讯，完成固件擦除、分包传输、跳转启动的完整升级流程。

- 协议来源：`GD32低压驱动器Boot升级协议.docx`
- 功能参考：C# WPF 版 `GD32FirmwareUpdater`
- 本版本：Qt/C++ 全新实现，功能等价 + 数据包明细表格（Model/View 教学演示）

---

## 二、运行环境

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 7 及以上（64 位） |
| 运行依赖 | 无需安装 Qt，使用 `build/` 发布包即可 |
| 硬件 | 电脑串口（USB转串口亦可），驱动器 Boot 供电 |
| 固件文件 | 二进制固件 `.bin`，≤ 2MB |

> **两种运行方式**：
> 1. **绿色发布包**：直接双击 `build/GD32FirmwareUpdaterQt.exe`（DLL 已随附）
> 2. **源码运行**：Qt Creator 打开 `GD32FirmwareUpdaterQt.pro`，选 MinGW 64bit 构建运行

## 四、操作步骤

### 第 1 步：串口设置与连接

1. **选择端口**：插入驱动器（或 USB 转串口）后点击 `[刷新]`，在下拉框选择对应 COM 口
2. **参数确认**（与协议默认一致，一般无需改动）：
   - 波特率：`115200`
   - 数据位：`8`
   - 停止位：`1`
   - 校验位：`EVEN`
3. 点击 `[打开串口]`，按钮变为 `[关闭串口]`，日志出现 `串口 COM5 已打开`
4. 可选：点击 `[查询版本]` 验证与设备通讯正常，成功则显示 Boot 版本号

### 第 2 步：选择固件文件

1. 点击 `[选择固件]`，选择 `.bin` 固件文件
2. 校验规则：文件必须存在、扩展名为 `.bin`、内容非空、≤ 2MB
3. 通过后界面显示文件路径与大小；失败则日志区红色提示

### 第 3 步：执行升级

1. 确认串口已打开、固件已载入
2. 点击 `[开始升级]`（此时该按钮禁用，`[取消升级]` 可用）
3. 观察进度：**请求 → 擦除 → 分包传输 → 跳转启动 → 完成**
   - 进度条实时推进（擦除阶段可能较长，约 30 秒内）
   - 数据包表格逐行新增，状态实时刷新
   - 日志区显示每一帧 TX/RX 十六进制报文
4. 完成后状态显示 `升级完成`，`[开始升级]` 恢复可用

### 第 4 步：取消 / 异常处理

| 情形 | 操作/表现 |
|------|-----------|
| 升级中需中止 | 点击 `[取消升级]`，流程立即结束 |
| 单帧通讯超时（5 秒） | 自动重试（最多 3 次），重试仍失败则整次升级失败 |
| Flash 擦除超时（30 秒） | 判定失败并结束 |
| 设备回复不匹配 | 提示 `CMD 不匹配`，按状态重试或失败 |
| 设备"跳转 App"慢 | 自动等待 2 秒后重发请求（Boot 就绪） |

> **失败后处理**：确认驱动器和串口连接、供电正常，重新打开串口后再次 `[开始升级]`。若设备被跳转到 App，需重新上电让设备进入 Boot。

### 第 5 步：清空日志

点击 `[清空日志]` 清空日志与数据包表格（下次升级也会自动清空）。

## 五、日志解读

日志格式：`[时间] [方向] 十六进制报文`

| 标记 | 含义 | 颜色 |
|------|------|------|
| `[TX]` | 本机发送的帧 | 蓝色 |
| `[RX]` | 设备回复的帧 | 绿色 |
| 失败/超时/取消 | 错误信息 | 红色 |
| 成功/完成 | 正常提示 | 绿色/灰白 |

**帧格式速查**（详细见技术协议）：

```
SOF=01  FUNC=06  CMD(2B大端)  DATALEN(2B小端)  DATA(...)  CRC(2B小端)
```

**升级命令**：

| 命令 | CMD | 作用 |
|------|-----|------|
| 升级请求 | 0x0010 | 询问设备是否就绪 |
| 升级启动（含擦除） | 0x0011 | 告知固件大小并擦除 Flash |
| 升级数据 | 0x0012 | 分包上传固件（每帧 ≤128B） |
| 跳转 App | 0x0013 | 升级完成，跳转运行新固件 |
| 查询版本 | 0x0014 | 读取 Boot 版本号 |

## 六、常见问题（FAQ）

**Q1：找不到 COM 口？**
→ 确认设备供电、驱动（如 CH340/CP2102）已安装；拔插后点击 `[刷新]`。

**Q2：点击打开串口失败？**
→ 端口可能被其他程序占用（串口调试助手等），关闭占用程序后重试。

**Q3：升级一直超时重试？**
→ 检查波特率/校验位是否正确；确认设备确实处于 **Boot 模式**（重新上电进入）；检查接线 TX/RX 是否交叉。

**Q4：选固件提示格式错误？**
→ 固件必须是 `.bin` 二进制文件（不能是 `.hex` 或文本），且 ≤ 2MB。

**Q5：如何验证软件是否正常？**
→ 程序自带冒烟模式：命令行运行 `GD32FirmwareUpdaterQt.exe --smoke`，1.5 秒后自动退出，退出码 0 表示正常。
