# GD32 低压驱动器固件升级工具 - 使用说明书

## 一、软件概述

**GD32 FirmwareUpdater** 是一款用于 GD32 低压驱动器的固件升级工具。通过串口（UART）与驱动器通讯，按照 GD32 低压驱动器 Boot 升级协议完成固件烧录。

**开发单位**: 苏州元磁智控科技有限公司

---

## 二、软件界面说明

### 2.1 主界面区域划分

软件主界面分为以下区域：

#### 1）标题栏（顶部蓝色区域）
- 显示软件名称
- 右侧显示当前连接的驱动器 Bootloader 版本号

#### 2）串口配置区（左上）
- **端口**: 下拉选择系统中的 COM 端口
- **刷新**: 重新扫描可用串口
- **波特率**: 通讯速率（默认 115200）
- **数据位**: 数据位数（默认 8）
- **停止位**: 停止位数（默认 1）
- **校验位**: 奇偶校验（默认 Even 偶校验）
- **连接指示灯**: 绿色=已连接，灰色=未连接
- **打开/关闭串口**: 切换串口连接状态

#### 3）固件文件区（左中）
- **文件路径**: 显示选中的固件文件路径
- **浏览**: 打开文件选择对话框
- **文件大小**: 显示固件文件大小

#### 4）操作控制区（左中下）
- **开始烧录**: 启动固件升级流程（绿色按钮）
- **取消烧录**: 中途取消升级操作（红色按钮）
- **查询版本号**: 查询已连接驱动器的 Bootloader 版本号

#### 5）升级进度区（左下）
- **进度条**: 图形化显示升级进度
- **百分比**: 数字显示当前进度
- **状态信息**: 文字描述当前操作阶段

#### 6）通讯日志区（右侧）
- 实时显示所有通讯日志
- **蓝色**: 发送数据（TX）
- **青色**: 接收数据（RX）
- **红色**: 错误信息
- **绿色**: 成功信息
- **清空日志**: 清除所有日志记录

#### 7）状态栏（底部）
- 显示当前操作状态和版权信息

## 三、操作流程

### 3.1 固件烧录流程

```
打开软件 → 选择COM端口 → 打开串口 → 选择固件文件 → 开始烧录 → 等待完成
```

**详细步骤**:

1. **连接硬件**: 使用串口线将电脑连接到 GD32 驱动器
2. **打开软件**: 运行 GD32FirmwareUpdater.exe
3. **选择端口**: 在"端口"下拉框中选择对应的 COM 端口（如找不到，点击"刷新"）
4. **配置参数**: 通常使用默认参数即可（115200, 8, 1, Even）
5. **打开串口**: 点击"打开串口"按钮，观察指示灯变为绿色
6. **选择固件**: 点击"浏览..."选择 `.bin` 格式的固件文件
7. **开始烧录**: 点击"开始烧录"，软件将自动执行以下步骤：
   - 发送升级请求，确认设备就绪
   - 通知设备擦除 Flash
   - 分包传输固件数据
   - 发送完成指令，设备跳转运行
8. **等待结果**: 观察进度条和日志，100% 即为成功

### 3.2 查询版本号

1. 确保串口已打开且设备连接正常
2. 点击"查询版本号"按钮
3. 版本号将显示在标题栏右侧

### 3.3 取消升级

在升级过程中，如需取消：
1. 点击红色"取消烧录"按钮
2. 软件将停止数据传输
3. **注意**: 取消后设备可能处于 Boot 模式，需重新烧录才能正常使用

---

## 四、注意事项

1. **切勿在升级过程中断电或拔线**，否则可能导致设备无法启动
2. 确保使用正确的固件文件，错误的固件可能使设备无法工作
3. 如果升级失败，设备通常会留在 Boot 模式，可重新尝试烧录
4. 串口波特率等参数必须与设备端配置匹配
5. 同一时间只能有一个程序占用 COM 端口

---

## 五、故障排除

| 现象 | 可能原因 | 解决方法 |
|------|----------|----------|
| 无法打开串口 | 端口被占用或不存在 | 关闭占用该端口的程序，检查设备连接 |
| 升级请求超时 | 设备未连接/未上电 | 检查硬件连接和供电 |
| Flash擦除超时 | 等待时间不够 | 正常情况最长30秒，等待即可 |
| 数据传输失败 | 通讯不稳定 | 检查线缆质量，降低波特率 |
| 升级后设备无反应 | 固件文件不匹配 | 确认固件版本与硬件型号对应 |

## 六、技术参数

| 参数 | 值 |
|------|-----|
| 支持固件格式 | .bin |
| 最大固件大小 | 2 MB |
| 数据帧最大载荷 | 128 字节/帧 |
| CRC校验算法 | CRC16/Modbus |
| 默认通讯参数 | 115200, 8, 1, Even |
| 通讯超时 | 5秒（擦除30秒） |
| 重试次数 | 3次 |
