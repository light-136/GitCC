# GD32 低压驱动器固件升级工具 - 快速启动指南

## 一、环境要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10/11 (64位) |
| 运行时 | .NET 8.0 Desktop Runtime |
| 开发工具 | Visual Studio 2022 / VS Code / dotnet CLI |
| SDK（开发） | .NET 8.0 SDK |

---

## 二、获取和编译

### 2.1 打开项目

```bash
# 进入项目目录
cd GD32FirmwareUpdater

# 还原NuGet包
dotnet restore

# 编译项目
dotnet build
```

### 2.2 运行程序

```bash
# 方式一：通过dotnet run启动
dotnet run --project src/GD32FirmwareUpdater

# 方式二：直接运行编译产物
src\GD32FirmwareUpdater\bin\Debug\net8.0-windows\GD32FirmwareUpdater.exe
```

### 2.3 运行测试

```bash
# 运行所有单元测试
dotnet test

# 详细模式
dotnet test --verbosity normal
```

### 2.4 发布独立包

```bash
# 发布为单文件可执行程序
dotnet publish src/GD32FirmwareUpdater -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -o publish
```

发布后的 `publish/GD32FirmwareUpdater.exe` 可直接在目标机器运行（无需安装.NET运行时）。

## 三、使用步骤（3分钟上手）

### Step 1: 连接硬件
1. 使用USB转串口线连接电脑和GD32驱动器
2. 确保驱动器已上电

### Step 2: 配置串口
1. 打开 GD32FirmwareUpdater
2. 点击"刷新"按钮扫描可用串口
3. 选择正确的COM端口
4. 串口参数使用默认值即可：
   - 波特率: 115200
   - 数据位: 8
   - 停止位: 1
   - 校验位: Even
5. 点击"打开串口"

### Step 3: 选择固件
1. 点击"浏览..."按钮
2. 选择 `.bin` 格式的固件文件
3. 确认文件大小显示正确

### Step 4: 开始烧录
1. 点击"开始烧录"按钮
2. 等待升级完成（观察进度条和日志）
3. 正常升级流程约10-30秒

### 完成
- 进度条到达100%且状态显示"固件升级成功！"即代表烧录完成
- 驱动器会自动从Boot跳转到App运行

## 四、常见问题

| 问题 | 解决方案 |
|------|----------|
| 未检测到COM端口 | 检查USB转串口驱动是否安装，设备管理器确认 |
| 打开串口失败 | 确认端口未被其他程序占用 |
| 升级请求超时 | 检查串口线连接，确认驱动器已上电 |
| Flash擦除超时 | 等待时间可能较长（最长30秒），请耐心等待 |
| 数据传输失败 | 检查串口线质量，降低波特率重试 |
| 跳转App失败 | 固件文件可能不兼容，检查固件版本 |
