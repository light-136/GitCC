# GD32 低压驱动器固件烧录上位机 - 开发规划文档

## 一、项目概要

### 1.1 项目名称
GD32 FirmwareUpdater — GD32低压驱动器固件升级工具（WPF版）

### 1.2 项目目标
基于《GD32低压驱动器Boot升级协议》，使用 C# WPF (.NET 8) 开发一个通过串口（UART）对 GD32 低压驱动器进行固件升级的上位机工具。参考 GigaDevice 官方 "GD32 All In One Programmer" 的界面风格和功能流程。

### 1.3 核心功能
1. **串口通讯管理**：自动扫描/手动选择COM口，配置波特率、数据位、停止位、校验位
2. **固件文件加载**：支持 `.bin` 格式固件文件的加载与解析
3. **固件烧录流程**：完整实现 Boot升级协议的四步升级流程
4. **进度显示**：实时显示烧录进度（进度条 + 百分比）
5. **日志系统**：实时显示通讯日志和操作日志
6. **版本查询**：查询 Bootloader 版本号

### 1.4 通讯协议总结（来源：GD32低压驱动器Boot升级协议）

| 步骤 | 指令 | CMD | 说明 |
|------|------|-----|------|
| 1 | UPGRADE_REQ | 0x0010 | 升级请求，询问驱动器是否具备升级条件 |
| 2 | UPGRADE_START | 0x0011 | 启动升级，发送文件大小，驱动器擦除Flash |
| 3 | UPGRADE_DATA | 0x0012 | 发送升级数据，每帧不超过128字节 |
| 4 | JUMP_APP | 0x0013 | 完成升级，驱动器从Boot跳转App |
| 5 | VER_REQ | 0x0014 | 请求Bootloader版本号 |

### 1.5 协议帧格式

```
| SOF(0x01) | FUNC(0x06) | CMD(2字节,大端) | DATALEN(2字节,小端) | DATA(N字节) | CRC(2字节,小端) |
```

## 二、意图分析

用户需要一个**可实际使用**的 WPF 固件烧录工具，满足以下核心需求：
1. 通过串口连接 GD32 驱动器
2. 加载 bin 固件文件
3. 按协议流程完成固件升级（请求→擦除→数据传输→跳转）
4. 提供友好的操作界面和状态反馈
5. 参考官方工具 GD32 All In One Programmer 的设计风格

## 六、软件流程

```
用户操作流程：
1. 打开软件
2. 选择COM口 → 配置串口参数（默认：115200, 8, 1, Even）
3. 点击"打开串口"
4. 点击"选择固件" → 选择 .bin 文件
5. 点击"开始烧录"
   ├── Step1: 发送升级请求 (0x0010) → 等待驱动器回复
   ├── Step2: 发送启动升级 (0x0011) → 驱动器擦除Flash
   ├── Step3: 循环发送数据 (0x0012) → 每包≤128字节
   └── Step4: 发送完成升级 (0x0013) → 驱动器跳转App
6. 烧录完成，显示结果
```

## 七、风险与注意事项

1. **CRC算法**：协议文档未明确CRC算法类型，需根据实际设备调试确认（默认实现CRC16/Modbus）
2. **超时处理**：串口通讯可能因设备未连接或故障导致超时，需设置合理超时时间
3. **线程安全**：串口数据接收在后台线程，需注意UI线程同步
4. **数据包大小**：升级数据每帧不超过128字节，需按此限制分包
5. **字节序**：CMD为大端模式，DATALEN和CRC为小端模式，需注意转换
