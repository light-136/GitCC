钩子数据流：

├── allow   → 放行操作

### 4.3 实践项目二：编写安全钩子（Day 3-5）

**任务**：创建一个 PreToolUse 钩子，阻止提交包含 TODO 的代码

```python
# 创建文件：.claude/hooks/check-todo.py
import json
import sys
import re

def main():
    # 从标准输入读取钩子数据
    input_data = json.load(sys.stdin)
    
    tool_name = input_data.get("tool_name", "")
    tool_input = input_data.get("tool_input", {})
    
    # 只检查 Edit 和 Write 操作
    if tool_name in ["Edit", "Write"]:
        content = tool_input.get("content", "") or tool_input.get("new_string", "")
        
        # 检查是否包含 TODO
        if re.search(r"TODO|FIXME|HACK", content):
            result = {
                "decision": "block",
                "reason": "代码中包含 TODO/FIXME/HACK 注释，请先处理后再提交"
            }
            print(json.dumps(result))
            return
    
    # 默认放行
    print(json.dumps({"decision": "allow"}))

if __name__ == "__main__":
    main()
```

## 八、常见问题 FAQ

### Q1：Claude Code 的核心代码在哪里？为什么我看不到？
**A**：Claude Code 的 CLI 核心运行时是**闭源**的，通过 npm/Homebrew 等方式分发。GitHub 仓库中公开的是**插件生态系统**、配置示例、CI/CD 模板和文档。

### Q2：我需要付费才能使用 Claude Code 吗？
**A**：需要。你需要一个 Anthropic 账号，并且 Claude Code 会消耗 Claude API 的 token 配额。

### Q3：学习这个项目需要什么前置知识？
**A**：
- **基础级**：会看 Markdown、了解 Git 基本操作
- **进阶级**：Python/Bash 脚本、JSON/YAML 格式
- **高级**：理解 LLM API、CI/CD 流程、企业安全策略

### Q4：我不是开发者，能从这个项目学到什么？
**A**：可以学到 AI 产品设计理念：
- 如何设计低门槛的扩展系统（Markdown即代码）
- 如何设计安全与功能的平衡（四层防护 + 灵活权限）
- 如何设计社区生态（插件市场 + 开发者工具）

### Q5：如何快速搭建一个类似的AI智能体系统？
**A**：核心步骤参考：
1. 选择一个 LLM API（如 Claude API）
2. 实现 ReAct 循环（推理 → 工具调用 → 观察）
3. 定义工具集（文件读写、命令执行等）
4. 添加安全层（权限控制、命令过滤）
5. 可选：添加插件系统、多智能体编排
