## 🎯 设计目标

### 核心目标
1. **完全离线运行** - 无需互联网，数据完全本地化
2. **高准确率** - 中文识别准确率达到 85%-92%
3. **低延迟** - 识别延迟控制在 1.5秒以内
4. **易用性** - 支持AirPods Pro等蓝牙耳机，即插即用
5. **可扩展** - 架构支持未来切换其他识别引擎

### 技术指标
- 音频采样率: 16kHz
- 音频通道: 单声道
- 识别延迟: < 1.5秒
- 系统响应: < 100ms
- 连续工作: 8小时+
- 数据丢失率: 0%

## 📦 技术栈详细说明

### 前端框架
- **WPF (Windows Presentation Foundation)**: .NET 8
- **MVVM框架**: CommunityToolkit.Mvvm 8.x
- **UI库**: MaterialDesignThemes 或 ModernWpf
- **依赖注入**: Microsoft.Extensions.DependencyInjection

### 音频采集
- **NAudio**: 2.2.1
  - WaveInEvent: 实时音频捕获
  - WaveFormat: 16kHz, 16bit, Mono
  - BufferedWaveProvider: 音频缓冲

### 语音识别
- **Whisper.cpp**: C++原生库
  - 模型选择: base/small 模型（平衡速度和准确率）
  - C# Wrapper: P/Invoke封装
  - VAD (Voice Activity Detection): 优化实时性

### 数据存储
- **SQLite**: Microsoft.Data.Sqlite 8.x
- **ORM**: Dapper 或 EF Core 8
- **连接池**: 支持并发访问

### 文件导出
- **EPPlus**: 7.x (Excel导出)
- **CSV**: CsvHelper (备选方案)

### 日志
- **Serilog**: 结构化日志
  - 文件输出
  - 控制台输出
  - 错误追踪

### 测试
- **xUnit**: 单元测试
- **Moq**: Mock框架
- **FluentAssertions**: 断言库

## 🗄️ 数据库设计

### 表结构设计

#### 1. VoiceRecords (语音记录表)
```sql
CREATE TABLE VoiceRecords (
    Id INTEGER PRIMARY KEY AUTOINCREMENT,
    RecordTime DATETIME NOT NULL,              -- 记录时间
    RecognizedText TEXT NOT NULL,              -- 识别文本
    RawText TEXT,                              -- 原始文本（未处理）
    AudioFilePath TEXT,                        -- 音频文件路径（可选）
    DeviceName TEXT,                           -- 设备名称
    Duration REAL,                             -- 音频时长（秒）
    Confidence REAL,                           -- 识别置信度
    Category TEXT,                             -- 分类（如：尺寸/外观/操作）
    Status TEXT,                               -- 状态（OK/NG）
    ProductId TEXT,                            -- 产品编号
    Operator TEXT,                             -- 操作员
    Remarks TEXT,                              -- 备注
    CreatedAt DATETIME DEFAULT CURRENT_TIMESTAMP,
    UpdatedAt DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 索引
CREATE INDEX idx_record_time ON VoiceRecords(RecordTime);
CREATE INDEX idx_status ON VoiceRecords(Status);
CREATE INDEX idx_category ON VoiceRecords(Category);
```

#### 2. Statistics (统计表)
```sql
CREATE TABLE Statistics (
    Id INTEGER PRIMARY KEY AUTOINCREMENT,
    StatDate DATE NOT NULL,                    -- 统计日期
    TotalRecords INTEGER DEFAULT 0,            -- 总记录数
    OkCount INTEGER DEFAULT 0,                 -- 合格数
    NgCount INTEGER DEFAULT 0,                 -- 不合格数
    PassRate REAL DEFAULT 0,                   -- 合格率
    CategoryStats TEXT,                        -- 分类统计（JSON）
    CreatedAt DATETIME DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(StatDate)
);
```

#### 3. DeviceSettings (设备设置表)
```sql
CREATE TABLE DeviceSettings (
    Id INTEGER PRIMARY KEY AUTOINCREMENT,
    DeviceName TEXT NOT NULL UNIQUE,           -- 设备名称
    DeviceId TEXT,                             -- 设备ID
    IsDefault INTEGER DEFAULT 0,               -- 是否默认
    SampleRate INTEGER DEFAULT 16000,          -- 采样率
    Channels INTEGER DEFAULT 1,                -- 声道数
    LastUsedAt DATETIME,                       -- 最后使用时间
    CreatedAt DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

#### 4. AppSettings (应用设置表)
```sql
CREATE TABLE AppSettings (
    Key TEXT PRIMARY KEY,                      -- 设置键
    Value TEXT,                                -- 设置值
    Description TEXT,                          -- 描述
    UpdatedAt DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

## ⚙️ Whisper.cpp 集成方案

### P/Invoke 封装设计
```csharp
/// <summary>
/// Whisper.cpp 原生接口封装
/// </summary>
public static class WhisperNative
{
    private const string DllName = "whisper.dll";
    
    [DllImport(DllName, CallingConvention = CallingConvention.Cdecl)]
    public static extern IntPtr whisper_init_from_file(string path_model);
    
    [DllImport(DllName, CallingConvention = CallingConvention.Cdecl)]
    public static extern void whisper_free(IntPtr ctx);
    
    [DllImport(DllName, CallingConvention = CallingConvention.Cdecl)]
    public static extern int whisper_full(
        IntPtr ctx,
        IntPtr wparams,
        float[] samples,
        int n_samples
    );
    
    [DllImport(DllName, CallingConvention = CallingConvention.Cdecl)]
    public static extern int whisper_full_n_segments(IntPtr ctx);
    
    [DllImport(DllName, CallingConvention = CallingConvention.Cdecl)]
    public static extern IntPtr whisper_full_get_segment_text(IntPtr ctx, int i_segment);
}
```

### 模型选择策略
- **base模型**: 74MB，速度快，准确率约85%（推荐用于实时场景）
- **small模型**: 244MB，速度中等，准确率约90%（推荐用于高准确率需求）
- **medium模型**: 1.5GB，速度慢，准确率约95%（可选，硬件较好时）

### 实时性优化策略
1. **VAD（Voice Activity Detection）**: 检测语音活动，只处理有效语音段
2. **音频分段**: 将长音频切分为小段（3-5秒），减少延迟
3. **线程池**: 使用独立线程处理识别，避免阻塞UI
4. **缓存预热**: 程序启动时预加载模型
