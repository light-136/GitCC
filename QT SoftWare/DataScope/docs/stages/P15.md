## 1. 阶段目标

实现数据记录与回放：`RecordManager` 把实时采集 DataPoint 流落盘为 CSV，并支持读回 CSV 后按时间戳重组为帧、用 QTimer 定时逐帧重放，驱动监控页波形重绘。同时完成集成冻结（停止新增功能 → 全量构建/测试 → windeployqt 部署 → 免安装发布包）与全项目文档收尾。

## 2. 关键技术点（WPF 迁移锚点）

- **QFile + QTextStream ≈ StreamWriter/StreamReader**：CSV 是工业数据交换通用格式，Excel/WPS 可直接打开。
- **记录 ≈ 后台订阅数据事件 → 写 StreamWriter**：`appendData` 由 `DataService::dataUpdated` 驱动，内部 `m_recording` 开关决定是否落盘（未记录时静默忽略）。
- **回放 ≈ 读文件 → 内存缓冲 → 定时器节拍重放**：`QTimer` 每 tick 发一帧 `replayData` 信号，复用 MonitorPage 同一 `onDataUpdated` 入口——**数据源可替换设计**闭环（P14 演示源 → P12 真实链路 → P15 回放数据）。
- **QHash 按时间戳分组 + `std::sort` 排序**：同一时间戳的多通道点视为一帧；QHash 无序必须显式排序保证回放顺序。

## 5. 遇到的难点与解决

- **QHash 无序需显式排序**：`framesByTime.keys()` 无序，直接遍历回放顺序错乱。解法：`std::sort` 按时间戳升序排成帧序列。
- **跨线程元类型注册**：`replayData(QVector<DataPoint>)` 参数过 QSignalSpy 需 `Q_DECLARE_METATYPE` + `qRegisterMetaType` 全限定名（与 P12 同源教训）。
- **畸形行容错**：CSV 空行/列数不足的畸形行跳过，不中断整个文件。
- **集成冻结纪律**：P15 前停止新增功能，所有 Agent 产出先编译测试再合入，最终一次 Release + windeployqt + 独立环境验证。
