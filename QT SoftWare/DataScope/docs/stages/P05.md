# P05 阶段学习文档 —— UI 基础 + 主窗口 + QSS 深色主题

> 提交：`2f90b07`（P3~P7 合并提交）｜ 里程碑：5 页签 UI 框架 + 深色主题

## 1. 阶段目标

把主窗口从空骨架升级为工业软件标准骨架：菜单栏 → 工具栏 → 中央 5 页签区 → 状态栏，并加载全局 QSS 深色主题。本阶段只搭框架与占位，各页签在后续阶段逐个填充真实功能。

## 2. 关键技术点（WPF 迁移锚点）

- **QMainWindow ≈ WPF MainWindow**：`menuBar()`/`addToolBar`/`statusBar()`/`setCentralWidget` 四块区域。
- **QTabWidget ≈ TabControl**：每个 QWidget 页 ≈ TabItem，`setDocumentMode(true)` 扁平化页签条（Chrome 风格）。
- **QSS ≈ App.xaml 全局 Style / ResourceDictionary**：类型选择器 `QPushButton` ≈ `TargetType`，ID 选择器 `#monitorPage` ≈ `x:Key`，`:hover/:selected` 伪状态 ≈ WPF Trigger。
- **菜单快捷键 `QKeySequence::Quit`** ≈ WPF `InputBinding`。

## 3. 实现内容

- `src/ui/mainwindow.h/.cpp`：`buildMenuBar`（文件/帮助菜单 + Ctrl+Q + 关于对话框）、`buildToolBar`（连接/启动/停止占位动作）、`buildCentralTabs`（5 页签）、`buildStatusBar`（左侧消息 + 右侧常驻时钟，QTimer 每秒刷新，复用 P4 定时器思路）、`applyStyleSheet`。
- `resources/qss/main.qss`：深色工业主题——深蓝灰背景 `#1e2a38`、页签青色高亮 `#16a085`、按钮 hover/pressed 三态、输入控件凹陷质感、日志区等宽字体深底绿字。注释明确"中文不写进 QSS"（编码兼容）。
- `resources/resources.qrc`：AUTORCC 把 `qss/main.qss` 编译进可执行文件，运行时路径 `:/qss/main.qss`。
- 5 个页面类 `src/ui/pages/`：MonitorPage / DevicePage / RecordPage / SettingsPage / DemoPage，各自独立 QWidget，由 U2 Agent 并行开发，主窗口只负责组装。

## 4. 测试与验证

无单测，界面人工验收：启动 DataScope.exe 检查页签切换、菜单/工具栏/状态栏齐全、深色主题生效。

## 5. 遇到的难点与解决

- **QSS 中文编码兼容性**：QSS 文件含中文在部分编译器/加载器下乱码或失效。解法：QSS 内全英文，中文只出现在 UI 文案（tr()）。
- **对象命名与选择器定位**：给页面设 `setObjectName`，QSS 用 ID 选择器精确命中单个控件，避免误伤全局同类型控件。
- **资源加载失败降级**：`qss.open()` 失败时 `qWarning` 并退化系统默认样式，不中断程序。

## 6. 阶段成果小结

主窗口成为"可挂载"的容器，5 页签 + 菜单/工具栏/状态栏骨架落定，深色主题全局统一。设计原则确立：**主窗口只负责组装，不写业务逻辑**；每页独立组件，为 P8/P9/P12/P14/P15 逐个填充预留插槽。
