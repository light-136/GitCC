# 07-设备状态机契约

> 适用范围：`DeviceController` 设备连接状态机，负责把 `DataService` 的"无状态"信号翻译为"有状态"的设备状态机，并驱动自动重连。状态枚举见 `src/domain/models.h` 的 `DeviceStatus`。

## 1. 状态集合

| 状态 | 枚举值 | 含义 |
| --- | --- | --- |
| Disconnected | 0 | 未连接（初始状态） |
| Connecting | 1 | 正在连接（异步过程中） |
| Connected | 2 | 已连接（采集可用） |
| Error | 3 | 出错（通信异常/设备离线） |

## 2. 状态转移表

| 当前状态 | 触发条件 | 下一状态 | 动作 |
| --- | --- | --- | --- |
| Disconnected / Error / Connecting | `connectDevice(host, port)` | Connecting | 保存目标、清重连计数、发起 `DataService::connectTo` |
| Connecting | `DataService::connected`（`onServiceConnected`） | Connected | 重置退避计数、停重连定时器 |
| Connecting | `DataService::connectionError`（`onServiceError`） | Error | 透传错误，非主动断开则启动退避重连 |
| Connected | `DataService::disconnected` 且非用户主动（`onServiceDisconnected`） | Error | 意外断线，启动退避重连 |
| Connected | `disconnectDevice()` | Disconnected | 标记主动断开、停定时器、`DataService::disconnectFromDevice` |
| Error / Connecting | 重连定时器超时（`onReconnectTimeout`） | Connecting | 用保存的 host/port 重新 `connectTo` |
| Error / Connecting / Connected | `disconnectDevice()` | Disconnected | 用户主动断开，不重连 |
| Connecting | `connectDevice`（已在 Connected 时） | 不变 | 忽略重复请求 |

## 3. 接口契约

公开方法：

| 方法 | 说明 |
| --- | --- |
| `status()` | 返回当前 `DeviceStatus` |
| `connectDevice(host, port)` | 异步连接；已 Connected 时忽略 |
| `disconnectDevice()` | 主动断开：任何状态 → Disconnected，并取消自动重连 |
| `startAcquisition()` / `stopAcquisition()` | 透传委托 `DataService` |

信号（实际签名，与源码逐一核对）：

| 信号 | 触发条件 |
| --- | --- |
| `statusChanged(DeviceStatus)` | 状态变化时广播（`setStatus` 幂等：状态未变不重复发） |
| `errorOccurred(QString)` | 错误 / 降级通知（连接失败、断线、重连提示等） |
| `dataUpdated(QVector<DataPoint>)` | DataService 数据逐级转发 |

委托关系：内部持有 `DataService *m_service`，订阅其 `connected` / `disconnected` / `connectionError` / `dataUpdated` 四个信号；设备状态由 `DeviceController` 维护，UI 只认状态机，不感知 DataService 细节。

## 4. 错误处理策略

- **退避重连**：初始 1s，每次失败翻倍，封顶 30s（`qMin(1000 << attempts, 30000)`）；仅 Error 态且非用户主动断开时生效；定时器单次触发，超时后由 `onReconnectTimeout` 决定是否再起。
- **`setStatus` 幂等**：目标状态与当前相同则直接返回，不广播 `statusChanged`。
- **主动/意外断开区分**：`disconnectDevice` 先置 `m_userDisconnected=true`；`onServiceDisconnected` 按该标志分流——主动则安静回 Disconnected，意外则进 Error 并重连。
- 重连定时器 `isActive()` 时保持当前间隔，防止"断线+错误"双重触发使退避跳档。

## 5. 重连前提

自动重连依赖 `AcquisitionWorker` 在收到 `errorOccurred` 时销毁 `m_client`（契约 06 / P13 修复）。否则残留客户端会使 `Worker::start` 因 `m_client` 非空而直接返回，吞掉重连请求。每次重连都是"新建一个全新连接"，而非在坏 socket 上重试。
