# 06-采集链路与数据总线契约

> 适用范围：采集工作线程（`AcquisitionWorker`）与主线程数据总线（`DataService`）之间的数据链路，以及帧 → 数据点转换规则。

## 1. 帧 → DataPoint 转换规则

`AcquisitionWorker::handleFrame` 对收到的合法帧做批量转换（**不校验 FUNC/CMD**，只要载荷非空即按 4 字节一组解析）：

| 规则项 | 约定 |
| --- | --- |
| 通道数 | `channelCount = payload.size() / 4`（float 字节数） |
| 通道顺序 | 按载荷字节顺序依次为通道 0、1、2、3… |
| 字节序 | 大端 4 字节位模式合成 32 位无符号整数，再按 float 位模式解释 |
| 数值类型 | 转换为 `double` 存入 `DataPoint::value` |
| 时间戳 | `QDateTime::currentDateTime()`（转换时刻） |
| 空载荷 | `channelCount <= 0` 时直接返回，不产出数据点 |
| 产出粒度 | 每帧产出一批 `QVector<DataPoint>`，每通道一个点 |

模拟设备采集帧载荷语义（契约 05）：`[通道0 温度 float][通道1 压力 float][通道2 流量 float][通道3 振动 float]`。数据节奏由模拟设备 50ms（20Hz）一帧驱动。

## 2. DataService 数据总线契约

公开方法：

| 方法 | 说明 |
| --- | --- |
| `connectTo(host, port)` | 队列投递 Worker::start，在采集线程创建 TcpClient 并异步连接；未初始化或已连接时发 `connectionError` 拒绝 |
| `disconnectFromDevice()` | 等价于停止采集（采集与连接共用一个 TcpClient） |
| `isConnected()` | 锁保护读取连接状态 |
| `startAcquisition()` | 置采集标志并发 `acquisitionStarted`；已采集时忽略 |
| `stopAcquisition()` | 清标志、队列投递 Worker::stop、发 `acquisitionStopped` 与 `disconnected` |
| `isAcquiring()` | 锁保护读取采集状态 |
| `lastData()` | 返回最近一批 `pointsReady` 的拷贝快照（锁保护） |

信号：

| 信号 | 触发条件 |
| --- | --- |
| `connected()` | Worker 报告连接成功 |
| `disconnected()` | Worker 报告断开 / `stopAcquisition` |
| `connectionError(QString)` | Worker 错误透传 |
| `dataUpdated(QVector<DataPoint>)` | 收到 Worker 投递的采样点后转发（UI 侧 MonitorPage 消费） |
| `acquisitionStarted()` / `acquisitionStopped()` | 采集启停 |

线程模型：DataService 运行于主线程；内部持有 QThread（采集线程）+ `moveToThread` 的 Worker；跨线程一律 QueuedConnection（`QVector<DataPoint>` 需在 main() 中 `qRegisterMetaType`），共享状态用 QMutex 保护。信号参数使用全限定名 `datascope::domain::DataPoint`，保证 moc 规范化名与注册名一致。

## 3. DataPoint 数据结构

`src/domain/models.h` 定义：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `channelIndex` | int | 所属通道序号（对应 Channel::index），默认 0 |
| `value` | double | 采样值（工程值），默认 0.0 |
| `timestamp` | QDateTime | 采样时刻，默认构造为无效时间 |

## 4. 采集启停语义

- `startAcquisition()` 幂等：`m_acquiring` 为真时直接返回，不重复启动。
- `stopAcquisition()` 幂等：Worker::stop 对 `m_client` 判空；重复调用安全。
- 启停只切换采集状态；实际 TCP 连接的创建/销毁由 Worker::start / Worker::stop 在采集线程完成。
- Worker::start 防重复：`m_client` 非空时直接返回（已在运行）。
- Worker::stop 与析构均销毁 `m_client`（异常退出时析构兜底清理）。
