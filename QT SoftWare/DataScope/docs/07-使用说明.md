# DataScope Studio 用户使用说明

> 适用版本：0.1.0 ｜ 运行环境：Windows ｜ 面向对象：现场操作员
> 配套程序：`DataScope.exe`（数据采集主程序）、`simulator.exe`（模拟采集设备）

---

## 1. 软件简介

**DataScope Studio** 是一套运行在 Windows 上的**工业多通道数据采集与实时监控系统**，通过 TCP 网络连接采集设备（真实设备或模拟设备），以实时曲线、仪表盘、指示灯三种方式直观展示 4 通道采集数据，并支持将数据记录为 CSV 文件、对历史数据逐帧回放分析。

### 主要功能

| 功能 | 说明 |
| --- | --- |
| 设备连接 | 一键连接采集设备（默认本机 `127.0.0.1:40001`），连接成功即自动开始采集 |
| 实时监控 | 4 通道（温度 / 压力 / 流量 / 振动）实时曲线、仪表盘、LED 状态灯、数值显示 |
| 数据记录 | 把采集数据实时落盘为 CSV 文件，Excel / WPS 可直接打开 |
| 历史回放 | 加载 CSV 记录文件，按帧逐条重放历史波形，带进度条 |
| 设备管理 | 采集设备的发现与配置入口（当前版本为占位页，功能后续版本开放） |
| 信号槽演示 | 内置 Qt 信号槽五种连接方式的教学演示（供学习参考） |

## 3. 快速开始（三步）

以下以"无真实硬件、使用模拟设备演示"为例：

### 第 1 步：启动模拟采集设备

双击运行 `simulator.exe`。程序以命令行窗口方式运行，看到如下输出即表示启动成功：

```
模拟设备已启动，监听 0.0.0.0:40001
模拟设备运行中，按 Ctrl+C 退出
```

> 模拟设备默认监听本机 `40001` 端口，每 50ms 向已连接的客户端发送一帧 4 通道正弦波数据，模拟真实的温度、压力、流量、振动采集。

### 第 2 步：启动 DataScope 主程序

双击运行 `DataScope.exe`。软件启动后**会自动尝试连接** `127.0.0.1:40001` 并自动开始采集，无需手工操作。

### 第 3 步：观察实时曲线

进入窗口后，默认停留在"**监控总览**"页签。可见 4 张通道卡片（温度 / 压力 / 流量 / 振动），每张卡片内的青色曲线持续滚动刷新，仪表盘指针同步摆动，LED 灯保持绿色，即代表采集链路已打通。

至此，三步完成，实时监控已开始运行。

> 若第 1、2 步顺序颠倒（先开主程序后开模拟设备），主程序会在状态栏提示连接错误，此时只需再点击工具栏的"**连接设备**"按钮即可重试连接。

## 5. 功能详解

### 5.1 连接与采集

**操作步骤：**

1. **启动采集设备**：先确保采集设备（或模拟设备 `simulator.exe`）已启动并监听 `40001` 端口。
2. **连接设备**：点击工具栏"**连接设备**"按钮。程序向 `127.0.0.1:40001` 发起 TCP 连接。
   - 连接过程中，状态栏消息区显示"正在连接 127.0.0.1:40001 ..."。
   - 连接成功：状态栏指示灯变绿显示"● 已连接"，消息区提示"设备已连接"，同时自动开始采集，监控页曲线开始滚动。
   - 连接失败：指示灯变红显示"○ 未连接"，消息区红色提示错误原因（如"错误：连接被拒绝"）。请检查设备是否启动、端口是否正确，然后重新点击"连接设备"。
3. **启动采集**：连接成功后自动处于采集状态；如执行过停止，可点击"**启动采集**"重新开始。
4. **停止采集**：点击"**停止采集**"，状态栏提示"已停止采集"，监控页数据停止刷新，波形停留在最后一帧。

> 提示：主程序**每次启动时都会自动连接** `127.0.0.1:40001` 并启动采集。日常使用中只要先开模拟设备（或真实设备），主程序打开即自动进入监控状态。

### 5.2 实时监控（监控总览页）

监控页纵向排列 **4 张通道卡片**，每张卡片对应一个采集通道：

| 通道 | 名称 | 单位 | 量程 | 报警阈值（85% 量程） |
| --- | --- | --- | --- | --- |
| 通道 0 | 温度 | ℃ | 0 ~ 100 | 85 |
| 通道 1 | 压力 | MPa | 0 ~ 10 | 8.5 |
| 通道 2 | 流量 | m³/h | 0 ~ 50 | 42.5 |
| 通道 3 | 振动 | mm/s | 0 ~ 5 | 4.25 |

每张卡片从左到右依次为：

```
┌──────────────────────────────────────────────────────────────┐
│  温度           (曲线标题 / 右上角"最新: 62.5")                │
│  ●  LED                                                      │
│  62.5 ℃        ╭──╮     实时曲线(青色)      │  ╭────╮  │
│  当前值         │  │                        │  │仪表盘│  │
│                 │  │                        │  ╰────╯  │
└──────────────────────────────────────────────────────────────┘
   ↑ 信息列(LED+数值)      ↑ 实时滚动曲线(弹性拉伸)   ↑ 仪表盘(固定宽)
```

**曲线**：
- 以青色折线绘制，Y 轴固定为通道量程（0 ~ 最大值），带 5 条水平网格线与刻度。
- 曲线从左向右填充，数据量达到上限后**自动滚动**，最新点始终锚定在右端。
- 曲线标题显示在左上角，右上角显示"最新: 数值"。

**仪表盘**：
- 270° 半圆表盘，带 0 / 25 / 50 / 75 / 100% 位置刻度，指针指向当前值。
- 表盘下方显示当前数值与单位。

**LED 状态灯含义**：
- **绿色**：数值正常（未超过报警阈值）。
- **红色**：数值超过报警阈值（量程上限的 85%），表示该通道**超限报警**。

**数值文本**：
- 显示当前采样值（保留 1 位小数），如 `62.5`。
- 若数值超过量程上限，会在数字后追加 `!` 提示符（如 `105.0 !`），此时曲线与指针已被自动钳制在量程边界。

### 5.3 数据记录（数据记录页）

实时把采集数据落盘为 CSV 文件。

**操作步骤：**

1. **确保正在采集**：先连接设备并处于采集状态（数据记录写入的是实时采集数据）。
2. 切换到"**数据记录**"页签。
3. 点击"**开始记录**"按钮：
   - 弹出"保存记录文件"对话框，默认文件名为 `record_年月日_时分秒.csv`（如 `record_20260814_143200.csv`），可自行选择保存目录与文件名。
   - 确认后即开始记录，状态标签变为"状态：正在记录 → 文件路径"。
   - 记录期间，"开始记录"按钮置灰、"停止记录"按钮亮起。
4. 点击"**停止记录**"按钮结束记录：
   - 程序会立即把缓冲区数据写入文件并关闭文件，状态标签变为"状态：已停止记录"。
   - 此时即可用 Excel / WPS / 记事本直接打开该 CSV 文件查看。

**CSV 文件格式说明：**

表头固定为三列，**每行记录一个采样点**：

```
timestampMs,channelIndex,value
1734168000123,0,42.5
1734168000123,1,0.8
...
```

| 列 | 含义 | 示例 |
| --- | --- | --- |
| `timestampMs` | 采样时刻的毫秒时间戳（自 1970-01-01 起的毫秒数） | `1734168000123` |
| `channelIndex` | 通道号（0=温度，1=压力，2=流量，3=振动） | `0` |
| `value` | 采样值（工程值） | `42.5` |

> 说明：同一采样时刻会产生 4 行（每通道一行）。停止记录时数据已落盘，无需额外"保存"操作。

### 5.4 历史回放（数据记录页）

把记录好的 CSV 文件重新逐帧播放，在监控页重现当时的波形。

**操作步骤：**

1. 切换到"**数据记录**"页签，在"历史回放"区域。
2. 点击"**加载回放文件...**"按钮：
   - 弹出"选择回放文件"对话框，选择之前记录的 CSV 文件。
   - 加载成功后，文件标签显示"文件：文件路径（N 帧）"，进度条量程变为该文件总帧数，"开始回放"按钮亮起。
   - 若文件为空或格式错误，程序会弹窗提示，此时"开始回放"保持置灰。
3. 点击"**开始回放**"按钮：
   - 程序按每帧约 100ms（10 帧/秒）的速度逐帧发送数据，**监控总览页的曲线 / 仪表盘 / LED 会随之重演**。
   - 回放期间"停止回放"按钮亮起，进度条实时前进（格式如 `3 / 10 帧`）。
4. 停止回放：点击"**停止回放**"即可暂停（再次点击"开始回放"会从第一帧重新播放）。
5. 播放完毕：进度条自动置满，按钮复位（"开始回放"重新亮起），如需重播再次点击"开始回放"即可。

> 说明：
> - 回放必须在"**监控总览**"页签可见时才能看到波形重演（回放数据走的是与实时采集相同的数据入口）。
> - 回放文件格式需与本软件记录的 CSV 格式一致（`timestampMs,channelIndex,value`），其他软件导出的 CSV 若列结构不同可能无法正确解析。

## 6. 常见问题（FAQ）

### Q1：启动 DataScope.exe 后连不上设备，状态栏显示红色"○ 未连接"怎么办？

1. 确认采集设备是否已启动。若用模拟设备，请先运行 `simulator.exe`，看到"模拟设备已启动，监听 0.0.0.0:40001"字样。
2. 确认端口一致：主程序固定连接 `127.0.0.1:40001`。若模拟设备用 `--port` 参数改过端口（如 `simulator.exe --port 40002`），主程序将无法连接，请使用默认端口 `40001`。
3. 确认防火墙是否拦截了本机回环连接（一般不会，可临时关闭防火墙测试）。
4. 上述无误后，点击工具栏"**连接设备**"按钮重试；若仍失败，重启主程序再试。

### Q2：启动主程序时提示连接错误，但我用的是真实设备？

请确认真实设备的 IP 与端口为 `127.0.0.1:40001`（本机回环地址）。如需连接远程设备，需要调整主程序中的连接地址（当前版本固定为 `127.0.0.1:40001`，后续版本会在设置页开放配置）。

### Q3：我录制的 CSV 文件保存在哪里？

录制前程序会弹出"保存记录文件"对话框，由你指定保存位置（默认建议文件名 `record_年月日_时分秒.csv`）。若想确认路径，可在停止记录前的状态标签中查看"状态：正在记录 → 具体路径"。

### Q4：回放 CSV 文件后，监控页上没有波形？

1. 确认回放的是本软件记录格式的文件（`timestampMs,channelIndex,value`），并已成功加载（文件标签显示"文件：路径（N 帧）"，N>0）。
2. 点击"开始回放"后，请切换到"**监控总览**"页签观察——回放数据驱动的是监控总览页的曲线。
3. 若进度条在走但监控页仍无曲线，请确认是否有其他操作导致采集处于异常状态，可重启主程序后重新加载回放。

### Q5：为什么我点"开始记录"后 CSV 里只有表头没有数据？

"开始记录"写入的是**实时采集数据**。若当前没有处于采集状态（未连接设备或已停止采集），数据流为空，CSV 只会写入表头。请先连接设备并确保状态栏为绿色"● 已连接"，再开始记录。

### Q6：监控页某个通道的 LED 变红了，代表什么？

代表该通道数值超过报警阈值（量程上限的 85%），触发超限报警。请关注该通道的实时数值与曲线，确认是否为设备异常或工艺波动。数值回落到阈值以下后 LED 会自动恢复绿色。

### Q7：状态栏的时钟显示"--:--:--"或不动？

状态栏时钟每秒刷新。若长时间无变化，可能是程序时钟定时器异常，重启主程序即可恢复。正常运行时显示如 `14:32:05`。

### Q8：可以同时记录多份数据吗？

当前版本同一时间只支持记录一份文件（开始新的记录会自动结束上一份记录）。如需分段记录，请先"停止记录"再"开始记录"生成新文件。

### Q9：模拟设备的命令行窗口可以关掉吗？

`simulator.exe` 是模拟设备的宿主进程，**关闭其命令行窗口即关闭模拟设备**，主程序会随之断开连接。请保持模拟设备窗口在采集演示期间持续运行。

### Q10：软件的日志在哪里？

软件启动时会在系统用户数据目录下初始化日志（基于 LogManager，路径位于当前用户的应用程序数据目录）。若软件异常，可将该目录下的日志文件提供给技术人员排查。
