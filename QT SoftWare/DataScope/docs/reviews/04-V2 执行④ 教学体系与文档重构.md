## 三、WPF→Qt 映射核心概念清单（wpf-qt-mapping.md 骨架）

| WPF 机制 | Qt 对应 | 本质区别（为何不能一一对应） | 本项目代码 |
|----------|---------|------------------------------|-----------|
| XAML + App.xaml | QSS + 资源系统 | XAML 声明式对象树 vs QSS 仅样式；无 DataTemplate | `resources/qss/main.qss`、`MainWindow::applyStyleSheet` |
| DependencyProperty | Q_PROPERTY | WPF 属性系统带变更通知/继承；Qt 是宏声明 + 手动信号 | `Q_PROPERTY`（widgets 控件）、元对象属性 |
| INotifyPropertyChanged | 信号 dataChanged | WPF 绑定引擎自动订阅；Qt 需手动 connect + emit | `dataUpdated`/`channelConfigReceived` 信号链 |
| ObservableCollection | QAbstractListModel | WPF 集合绑定自动同步；Qt 需实现 rowCount/data 并手动 begin/end 插入 | `DeviceListModel`/`AlarmEventModel` |
| Binding + Mode | Model/View + role | WPF 双向绑定语言级；Qt 靠 delegate 取 role 数据，编辑走 setData | `QListView + QAbstractListModel` |
| DataTemplate | QStyledItemDelegate | WPF 任意对象模板化；Qt 委托绘制是命令式 | 自绘控件（LineChartWidget 等）替代 |
| Dispatcher（线程亲和） | 事件循环 + 线程亲和 | WPF Dispatcher.Invoke vs Qt 队列连接 + moveToThread | `QThread + AcquisitionWorker + QueuedConnection` |
| async/await | 信号槽 + Worker | C# 编译器状态机 vs Qt 事件驱动回调 | `DataService.connectTo` 异步 + connected 信号 |
| BackgroundWorker | QThread + Worker | 语义相近：后台 + 进度 + 完成 | `AcquisitionWorker`（P12） |
| 事件（RoutedEvent） | 信号槽 | WPF 路由事件冒泡/隧道；Qt 直连广播 | `SignalSlotDemo` 五种连接 |
| Command（ICommand） | QAction | WPF 命令带 CanExecute 绑定；Qt 动作 + setEnabled 手动 | 工具栏 `QAction` |
| 布局（Grid/StackPanel） | 布局管理器 | WPF 绝对+相对坐标混合；Qt 布局类自动算几何 | `QVBoxLayout/QHBoxLayout` |
| 触发器/动画 | 无直接对应 | WPF 声明式动画；Qt 需 QVariantAnimation 手写 | 自绘控件内 QTimer |
| 样式触发器 | QSS 选择器 + 属性 | WPF 更细粒度；Qt QSS 有限 | `QSS #objectName` 定位 |

## 四、Level 1-7 学习路径（learn/README.md 骨架）

| Level | 能力 | 载体 | 练习 |
|-------|------|------|------|
| 1 | 看懂代码 | 架构导览 + 源码行走 | 走一遍 connectDevice 数据流，画调用链 |
| 2 | 修改功能 | 改通道数/量程/报警规则 | 模拟设备 6 通道 + 自定义量程 |
| 3 | 独立增加模块 | 增加新设备类型 | 新增"串口设备"占位（P9 预留） |
| 4 | 独立写 Qt 软件 | 小型完整应用 | 用 SignalSlotDemo 思路写一个定时计数器 |
| 5 | 设计 Qt 架构 | 分层 + Model/View | 给监控页数据加第二消费者 |
| 6 | 线程/网络/协议/生命周期 | V2 深度专题 | 复现断线注入并解释重连 |
| 7 | 读大型 Qt 项目 | 迁移实践 | 读 Qt 官方 example 对照本项目 |
