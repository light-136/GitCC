# 二十二、WPF → Qt 教学规则

我熟悉 WPF，所以每个核心技术都应该尽量提供：

```text
WPF 思路
↓
Qt 思路
↓
代码对比
↓
底层机制差异
↓
为什么不能简单照搬
```

例如：

```text
Window
→ QMainWindow

UserControl
→ QWidget

DispatcherTimer
→ QTimer

TcpClient
→ QTcpSocket

ObservableCollection
→ Model/View

INotifyPropertyChanged
→ dataChanged / signals

Dispatcher
→ Event Loop / QueuedConnection
```

但是必须明确：

> **类比只是学习辅助，不代表两个框架内部机制相同。**

特别需要讲清：

* GC vs RAII
* Binding vs Model/View
* async/await vs Event Loop
* Routed Event vs Qt Event
* DependencyProperty vs Qt Property
* Dispatcher vs Qt Event Loop
* MVVM 在 WPF 与 Qt 中的差异
