## 一、规程目标

本报告规定 DataScope Studio 从需求到交付的**开发过程规程**，保证：
1. **质量**：每一阶段"编译→测试→文档→验收"闭环，错误就地修正；
2. **速度**：契约先行 + 多 Agent 并行，接口定死即可并行开发；
3. **稳定**：P15 前集成冻结，杜绝"最后一刻大改"；
4. **可交付**：最终产出"无 Qt 环境可运行的部署包 + 全量文档 + 最终报告"。

## 三、每阶段必走流程（阶段循环）

```
┌──────────────────────────────────────────────────────┐
│ 1. 契约先行：写接口契约文档（签名字段、语义、测试强制项） │
│ 2. 实现：主 Agent 或专项 Agent 按契约编码              │
│ 3. 集成：主 Agent 集成到 CMakeLists（唯一维护者）       │
│ 4. 编译：一键构建，错误就地修正                        │
│ 5. 测试：ctest 全部通过（每阶段新增套件）              │
│ 6. 冒烟：主程序启动验证（GUI 无回归）                 │
│ 7. 文档：写《阶段N小结》（stages/P0N.md）              │
│ 8. 提交：git 里程碑提交                              │
└──────────────────────────────────────────────────────┘
```

## 四、多 Agent 协作规程（主 Agent + 专项 Agent）

| 规则 | 说明 |
|------|------|
| 文件所有权隔离 | 每个专项 Agent 只写自己的文件，CMakeLists 由主 Agent 唯一维护 |
| 契约先行 | 接口契约文档定死后，实现/测试/主 Agent 三方并行 |
| 有依赖串行 | 后阶段依赖前阶段产出，未就绪不开工 |
| 无依赖并行 | 领域/协议/控件等独立模块可同时开发 |
| 测试独立 | 测试 Agent（T3）独立于开发 Agent 验证契约 |
| P15 集成冻结 | 冻结后不再新增功能，只修 bug + 部署 |

## 五、编码规范执行

- **语言**：C++17，Qt 5.12.2（mingw73_64 套件，非 Qt6）。
- **命名**：类/文件 PascalCase，成员 `m_xxx`，常量 `kXxx`，枚举 `enum class`。
- **注释**：代码注释、类、函数、变量命名解释**全部中文**；教学点对照 WPF/C#。
- **架构**：UI→app→services→domain/protocol→infrastructure→utils 严格分层。
- **错误处理**：解析类 TryParse 风格（返回 bool，不抛异常）；UI 状态栏提示 + 日志落盘。
- **线程**：跨线程数据一律信号槽 QueuedConnection；QMutex 保护共享缓冲。

## 六、测试规程

- **框架**：Qt Test + CTest（`enable_testing()` + `add_test`）。
- **每模块至少一个 `tst_xxx.cpp`**，测试 target 与库 target 同名前缀。
- **强制项**：契约文档"测试强制项"必须全部覆盖（数据驱动 / QSignalSpy / 边界）。
- **全量回归**：每次集成后跑完整 `ctest`，8 套件全绿才允许提交。
- **端到端冒烟**：主程序启动（HANDLE 非 0）+ 监控页演示动画。

## 八、变更控制

- **版本**：主版本 0.1.x；功能变更走 P 阶段，Bug 修复随时。
- **契约变更**：改契约必须先改契约文档（同步测试强制项），再改代码。
- **目录红线**：不删除用户任何文件夹；只允许在 `QT SoftWare` 目录内做工程清理。

## 十、风险与对策

| 风险 | 对策 |
|------|------|
| 线程竞态 | 主 Agent 亲写 P12，跨线程只走 QueuedConnection，共享缓冲加锁 |
| 协议两端不一致 | 契约先行 + CRC 标准向量 + 粘包/半包单测 |
| 界面卡顿 | 采集线程不碰 UI；QTimer 合并重绘 |
| 部署缺 DLL | `ds_deploy_qt` CMake 函数自动 windeployqt |
| 时间紧 | 多 Agent 并行 + 契约先行 + 集成冻结 |
