## 一、设计原则

- **纯数据模型**：不依赖 UI、不依赖 QtNetwork/SerialPort，只依赖 QtCore（QString/QDateTime/QVector）。
- **值语义**：Channel/DataPoint 用 struct（值类型，可拷贝）；Device 用 class 管理一组 Channel。
- 对应 WPF/C#：DTO/POCO（`public class Device { public string Name { get; set; } }`）。

## 二、接口契约（`src/domain/models.h`，命名空间 `datascope::domain`）

```cpp
// 设备状态枚举
enum class DeviceStatus { Disconnected = 0, Connecting, Connected, Error };

// 采集通道（值类型）
struct Channel {
    int index = 0;       // 通道序号（0 基）
    QString name;        // 通道名（如 "温度"）
    QString unit;        // 单位（如 "℃"）
    double scale = 1.0;  // 缩放系数（原始值 × scale + offset）
    double offset = 0.0; // 偏移量
};

// 一次采样数据点（值类型）
struct DataPoint {
    int channelIndex = 0;  // 所属通道序号
    double value = 0.0;    // 采样值（已缩放）
    QDateTime timestamp;   // 采样时刻
};

// 设备（一组通道 + 状态）
class Device
{
public:
    Device() = default;

    // ---- 只读访问 ----
    QString id() const;                 // 设备唯一标识
    QString name() const;               // 设备名称
    DeviceStatus status() const;        // 连接状态
    int channelCount() const;           // 通道数量
    const QVector<Channel> &channels() const;  // 全部通道（只读引用）

    // ---- 写操作 ----
    void setId(const QString &id);
    void setName(const QString &name);
    void setStatus(DeviceStatus status);
    void addChannel(const Channel &ch);
    void clearChannels();

private:
    QString m_id;
    QString m_name;
    DeviceStatus m_status = DeviceStatus::Disconnected;
    QVector<Channel> m_channels;
};
```

## 三、测试强制项（`tests/unittests/tst_domain.cpp`）

1. 默认状态：新建 Device 的 status == Disconnected、channelCount == 0；
2. id/name 读写往返；
3. addChannel 后 channelCount 与 channels() 内容一致；
4. clearChannels 后 count == 0；
5. Channel 值语义：拷贝后修改副本不影响原对象；
6. DataPoint 字段默认值正确。
