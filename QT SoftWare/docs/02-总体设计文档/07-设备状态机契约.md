## 一、状态定义（复用 P8 `datascope::domain::DeviceStatus`）

```cpp
enum class DeviceStatus { Disconnected = 0, Connecting, Connected, Error };
```

| 状态 | 含义 | 允许进入的转移 |
|------|------|---------------|
| Disconnected | 未连接（初始态） | → Connecting（发起连接）/ → Error（连接即失败） |
| Connecting | 正在连接（异步中） | → Connected（成功）/ → Error（失败/超时）/ → Disconnected（取消） |
| Connected | 已连接（采集可用） | → Disconnected（断开）/ → Error（通信异常） |
| Error | 出错（可重试） | → Connecting（重连）/ → Disconnected（放弃） |

## 二、状态转移表

```
 Disconnected ──connectTo()──► Connecting ──TCP connected──► Connected
      ▲                           │  ▲                          │
      │                           │  │ TCP error/timeout         │ 链路异常
      │  disconnect/cancel        │  ▼                          │
      └───────────────────────────┴─► Error ◄────────────────────┘
                                          │
                   重试(带退避) ──► Connecting
```

## 三、接口契约（`src/services/devicecontroller.h`，命名空间 `datascope::services`）

```cpp
namespace datascope::services {

class DeviceController : public QObject {
    Q_OBJECT
public:
    explicit DeviceController(QObject *parent = nullptr);

    // ---- 状态查询 ----
    datascope::domain::DeviceStatus status() const;   // 当前状态

    // ---- 状态驱动操作 ----
    void connectDevice(const QString &host, quint16 port);  // → Connecting → Connected
    void disconnectDevice();                               // → Disconnected
    void startAcquisition();
    void stopAcquisition();

signals:
    void statusChanged(datascope::domain::DeviceStatus status);  // 状态转移通知
    void errorOccurred(const QString &message);                  // 错误降级通知
    void dataUpdated(const QVector<datascope::domain::DataPoint> &points);  // 转发数据

private:
    datascope::domain::DeviceStatus m_status = datascope::domain::DeviceStatus::Disconnected;
    // ... 持有 DataService / 重连定时器（P13 实现细节）
};

}
```

## 四、错误处理策略

| 错误场景 | 处理 | 用户感知 |
|----------|------|---------|
| 连接失败（拒绝/超时） | → Error + errorOccurred | 状态栏提示 + 日志 |
| 连接后断线（TCP 断开） | → Error + 自动重连（退避：1s/2s/4s...封顶 30s） | 状态栏提示"设备离线，重连中" |
| 帧校验失败 | 丢弃坏帧（P10 解析器已保证） | 静默（日志 trace） |
| 通道越界 | 跳过该 DataPoint | 静默 |
| 采集线程异常 | → Error + stopAcquisition | 状态栏提示 + 日志 |

## 五、测试强制项（`tests/unittests/tst_devicecontroller.cpp`）

1. 初始状态 Disconnected；
2. connectDevice → 回环伪设备 → 状态经 Connecting→Connected（QSignalSpy 监听 statusChanged）；
3. 连不存在端口 → Error + errorOccurred；
4. disconnectDevice → Disconnected；
5. Error 态自动重连：伪设备先拒后收 → 最终 Connected（退避重试）；
6. 采集数据流转发：connectDevice + startAcquisition → dataUpdated 触发。

## 六、与其它模块关系

- 依赖 P12 DataService（实际连接/采集动作）、P8 DeviceStatus（状态定义）、P11 TcpClient。
- P14 MonitorPage 展示状态：LED 绿=Connected、红=Error、灰=Disconnected。
