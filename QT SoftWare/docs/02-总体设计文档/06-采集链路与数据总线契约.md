## 一、总体数据流（P12 目标态）

```
┌─ 采集线程 (QThread Worker) ──────────────┐
│  TcpClient（P11 交付）                     │
│   → readyRead → FrameParser.feed → 帧     │
│   → 解析 DataPoint 列表                    │
│   → emit pointsReady(QVector<DataPoint>)  │
└─────────────────┬─────────────────────────┘
                  │ QueuedConnection（跨线程安全投递）
                  ▼
┌─ 主线程 ─────────────────────────────────┐
│  DataService（数据总线，P12 交付）          │
│   → emit dataUpdated(QVector<DataPoint>) │
│   → MonitorPage::onDataUpdated（P14 已就位）│
└──────────────────────────────────────────┘
```

关键点：**UI 永不直接接触采集线程**；所有跨线程数据经 `DataService` 的信号（队列连接）投递。MonitorPage 已预留 `onDataUpdated(QVector<DataPoint>)`（P14 的"数据源可替换"设计）。

## 二、DataService 接口契约（`src/services/dataservice.h`，命名空间 `datascope::services`）

```cpp
namespace datascope::services {

class TcpClient;   // P11 交付

class DataService : public QObject {
    Q_OBJECT
public:
    explicit DataService(QObject *parent = nullptr);

    // ---- 连接控制 ----
    void connectTo(const QString &host, quint16 port);  // 经 TcpClient
    void disconnectFromDevice();
    bool isConnected() const;

    // ---- 采集控制 ----
    void startAcquisition();   // 启动采集线程
    void stopAcquisition();
    bool isAcquiring() const;

    // ---- 通道配置（P14 演示参数在真实链路里由此替代）----
    void setChannels(const QVector<domain::Channel> &channels);

    // ---- 最新数据快照（供回放/CSV 读取）----
    QVector<domain::DataPoint> lastData() const;

signals:
    void connected();
    void disconnected();
    void connectionError(const QString &message);
    void dataUpdated(const QVector<domain::DataPoint> &points);  // 主线程发出
    void acquisitionStarted();
    void acquisitionStopped();

private:
    TcpClient *m_client = nullptr;      // TCP 客户端（P11）
    QThread   *m_thread = nullptr;      // 采集线程
    // ... Worker 对象、互斥锁等（P12 实现细节）
};

}
```

## 三、采集线程 Worker 契约（`src/services/acquisitionworker.h`）

```cpp
namespace datascope::services {

class AcquisitionWorker : public QObject {
    Q_OBJECT
public:
    explicit AcquisitionWorker(TcpClient *client, QObject *parent = nullptr);
    // 注意：TcpClient 运行在采集线程（moveToThread 后创建），
    //       FrameParser 在 Worker 内部驱动

public slots:
    void start();                       // 线程内开始采集（启动帧请求）
    void stop();                        // 线程内停止

signals:
    void pointsReady(const QVector<domain::DataPoint> &points);  // 产出的采样点
    void frameParsed(const protocol::ProtocolFrame &frame);      // 解析出的帧（调试）
};

}
```

## 四、帧 → DataPoint 的转换规则（Worker 内部）

模拟设备数据帧（CMD=0x01 采集数据）载荷布局：
```
DATA = 4 通道 × 4 字节 float（大端）
  通道0 温度 float | 通道1 压力 float | 通道2 流量 float | 通道3 振动 float
```
转换：
- 每帧产出 4 个 DataPoint（channelIndex = 0..3）；
- value = 解析出的 float（浮点大端拼装：QDataStream 或位运算）；
- timestamp = QDateTime::currentDateTime()；
- 帧带 `func | 0x80` 表示响应帧：解析其 CMD==0x01 的响应（采集数据帧）。

**坐标系约定**：模拟设备发正弦波（与 P14 演示参数一致：温度 0-100、压力 0-10、流量 0-50、振动 0-5），保证 UI 量程匹配。

## 五、线程安全设计（P12 核心教学点）

| 项目 | 设计 |
|------|------|
| 跨线程数据 | 一律信号槽 **QueuedConnection**（QVector<DataPoint> 隐式共享，拷贝便宜） |
| TcpClient 归属 | moveToThread 后线程内创建，I/O 不阻塞 UI |
| 共享缓冲 | `lastData()` 读最新快照：QMutex 保护（Writer 线程 + UI 线程） |
| 线程生命周期 | Worker::deleteLater + thread.quit()/wait()；主程序退出先 stopAcquisition |

## 六、测试强制项（`tests/unittests/tst_dataservice.cpp`）

1. **连接控制**：connectTo 到本地回环伪设备 → connected 信号（QSignalSpy）；
2. **采集链路冒烟**：伪设备按 50ms 发采集帧 → 等 ~300ms → dataUpdated 至少触发 2 次，且 points 中每帧含 4 个 DataPoint；
3. **停止采集**：stopAcquisition 后 dataUpdated 不再触发（计数不变）；
4. **断开**：disconnectFromDevice 后 isConnected()==false；
5. **通道越界防御**：构造 channelIndex 越界的帧，Worker 跳过不崩溃。
6. （可选）**线程安全冒烟**：采集 500ms 后读取 lastData()，无崩溃、点数>0。

> Simulator 为独立程序，主 Agent 集成时以"启动 Simulator → 主程序连接 → 曲线动起来"作为端到端冒烟验证。
