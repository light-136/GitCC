## 一、帧格式（字节布局）

| 字段 | 长度 | 说明 |
|------|------|------|
| SOF  | 2B   | 帧头，固定 `0xAA 0x55`（用于接收端重同步） |
| FUNC | 1B   | 功能码（见下） |
| CMD  | 1B   | 子命令（各功能内部定义） |
| LEN  | 2B   | 载荷长度，**大端序**（高字节在前） |
| DATA | LEN  | 载荷数据（可为空，LEN=0） |
| CRC16| 2B   | 校验码，覆盖 **FUNC 起到 DATA 末尾** 的所有字节，MODBUS CRC16，**低字节在前** |

```
字节序号:  0      1      2      3      4      5      6 ... 6+LEN-1  6+LEN    6+LEN+1
          +------+------+------+------+------+------+------+------+------+------+
          | 0xAA | 0x55 | FUNC | CMD  | LEN_H| LEN_L| D0   | ...  | DN-1 | CRC_L| CRC_H|
          +------+------+------+------+------+------+------+------+------+------+
```

## 二、功能码（FUNC）

| 值 | 名称 | 说明 |
|----|------|------|
| 0x01 | Acquire | 采集命令（上位机 → 设备） |
| 0x02 | Config  | 配置命令 |
| 0x03 | Query   | 状态查询 |
| 0x80 | Response | 响应标志：`FUNC | 0x80` 表示该帧是响应帧（如 0x81=采集响应） |

## 三、CRC16（MODBUS）

- 算法：MODBUS CRC16，初始值 `0xFFFF`，多项式 `0xA001`（反转表驱动），输入为 **FUNC..DATA** 全部字节。
- 追加顺序：**低字节在前**（先 CRC_L 再 CRC_H），与 MODBUS 串口惯例一致。

## 四、C++ 接口契约（P10 协议引擎实现依据）

命名空间 `datascope::protocol`，文件 `src/protocol/`：

```cpp
// 帧结构（解析结果）
struct ProtocolFrame {
    quint8 func = 0;        // 功能码原始值（0x01/0x02/0x03/0x81...）
    quint8 cmd = 0;         // 子命令
    QByteArray payload;     // 载荷
    bool isValid = false;   // 校验通过 = true
};

// 组帧器：把 功能码+子命令+载荷 构造成完整帧字节流
class FrameBuilder {
public:
    static QByteArray build(quint8 func, quint8 cmd, const QByteArray &payload);
};

// 流式解析器：处理半包/粘包/错位重同步
class FrameParser {
public:
    void feed(const QByteArray &chunk);   // 喂入原始字节流
    bool nextFrame(ProtocolFrame &out);   // 取出下一帧，无完整帧返回 false
    int bufferedBytes() const;            // 缓冲区剩余未消费字节数
private:
    QByteArray m_buffer;                  // 累积缓冲
};

// CRC16 工具
class Crc16 {
public:
    static quint16 compute(const QByteArray &data);   // 输入 FUNC..DATA
};
```

## 五、测试强制项（tst_protocol.cpp）

1. 组帧 → 解析 往返一致（多种 func/cmd/载荷）；
2. 半包：把一帧拆成两段 feed，仍能完整解析；
3. 粘包：一个 feed 里塞两帧，能逐帧取出；
4. CRC 篡改 → 该帧 isValid=false 且被跳过（不产出错误帧）；
5. SOF 错位：帧头前混入垃圾字节能重同步；
6. LEN 越界保护：LEN 声称超大（如 0xFFFF）不导致缓冲区膨胀/崩溃；
7. 空载荷（LEN=0）正常往返；
8. 边界：单字节 feed、空 feed。
