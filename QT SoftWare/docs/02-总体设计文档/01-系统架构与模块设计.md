## 一、系统概述

DataScope Studio 是工业多通道数据采集与实时监控桌面软件。目标：
- 通过**串口 / TCP** 连接采集设备，按自定义**帧协议**解析数据；
- 在**监控页**以实时曲线、仪表盘、LED 可视化各通道数据；
- 支持配置持久化、日志、报警、数据记录与回放、CSV 导出。
- 附带独立的 **DataScope Simulator**（模拟设备程序）用于无硬件联调。

技术栈：C++17 ｜ Qt 5.12.2 (Widgets) ｜ CMake + Ninja ｜ QtTest/CTest。

## 五、关键数据流（采集链路，P15 目标态）

```
模拟设备(Simulator, QTcpServer)
  → 按帧格式发数据帧
TcpClient(QTcpSocket)
  → readyRead 收到字节流 → feed() 给 FrameParser
FrameParser 状态机
  → 校验 SOF/LEN/CRC → 产出 ProtocolFrame
采集线程 / DataService
  → 解析 frame → 生成 DataPoint(channelIndex, value, timestamp)
  → emit dataUpdated(QVector<DataPoint>)
MonitorPage 槽
  → LineChartWidget::appendPoint(v) / GaugeWidget::setValue(v) / Led::setState()
  → QTimer 刷新 UI（或信号驱动）
```

## 六、线程模型（P12 规划）

| 线程 | 职责 | 与主线程交互 |
|------|------|-------------|
| 主线程(UI) | 事件循环、界面刷新 | — |
| 采集线程(QThread) | 读串口/TCP、解析、组包 | 信号槽 **QueuedConnection** 投递 DataPoint |
| Simulator(独立进程) | 模拟设备产生数据 | TCP 与主程序连接 |

要点：IO 不阻塞 UI；跨线程数据用信号槽（队列）投递；QMutex 保护共享缓冲。

## 八、错误处理与日志

- 统一日志：`LogManager::instance().error("Module", "desc")`（文件 + 信号双通道）。
- 解析类错误：TryParse 风格返回 bool，不抛异常。
- UI 层错误：状态栏提示 + 日志落盘。

## 九、构建与测试

- CMake 结构：`datascope_utils`(静态库) + `datascope_infra`(静态库) + `datascope_domain`(P8) + `datascope_protocol`(P10) + `DataScope`(主程序) + `tst_*`(QtTest)。
