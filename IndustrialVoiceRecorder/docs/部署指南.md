# 工业语音记录系统 - 部署指南

## 一、系统要求

### 硬件要求
| 项目 | 最低要求 | 推荐配置 |
|------|---------|---------|
| CPU | Intel i5 第8代 | Intel i7 / AMD R5 |
| 内存 | 8GB | 16GB |
| 硬盘 | 2GB可用空间 | SSD, 5GB+ |
| 蓝牙 | 4.0+ | 5.0+ |

### 软件要求
- Windows 10/11 (64位)
- .NET 8.0 Runtime
- Python 3.8+（推荐3.10）

---

## 二、部署包内容

将以下目录打包为zip发送到目标电脑：

```
IndustrialVoiceRecorder/
├── src/IndustrialVoiceRecorder.WPF/bin/Debug/net8.0-windows/  ← 程序主目录
│   ├── IndustrialVoiceRecorder.WPF.exe  ← 主程序
│   ├── config.txt                        ← 配置文件（可修改）
│   ├── *.dll                             ← 依赖库
│   ├── Data/                             ← 数据库（自动创建）
│   ├── Export/                           ← 导出文件
│   ├── Logs/                             ← 日志
│   └── Models/                           ← Whisper模型（可选）
├── funasr/
│   ├── funasr_server.py                  ← FunASR服务脚本
│   ├── 启动FunASR服务.bat                ← 一键启动
│   └── 安装FunASR.bat                    ← 一键安装
└── docs/                                 ← 文档
```

---

## 三、目标电脑安装步骤

### 步骤1：安装.NET 8 Runtime
下载地址: https://dotnet.microsoft.com/download/dotnet/8.0
- 选择 `.NET Desktop Runtime 8.0.x` (Windows x64)
- 安装后验证: 打开CMD运行 `dotnet --info`

### 步骤2：安装Python
下载地址: https://www.python.org/downloads/
- 推荐 Python 3.10
- **安装时务必勾选 "Add Python to PATH"**
- 验证: 运行 `python --version`

### 步骤3：安装FunASR
打开CMD，执行：
```bash
pip install funasr modelscope torch torchaudio flask -i https://mirrors.aliyun.com/pypi/simple/
```

> 详细教程见 `FunASR部署教程.md`

### 步骤4：复制程序文件
将部署包解压到目标电脑的任意目录，如 `D:\IndustrialVoiceRecorder\`

### 步骤5：修改配置文件
编辑 `config.txt`，根据实际环境修改：
```
FunASR.Host=127.0.0.1    ← 如果FunASR在另一台电脑，改为那台电脑的IP
FunASR.Port=10095         ← 端口号
```

> 详细配置说明见 `config配置说明.md`

## 四、启动顺序

### 第1步：启动FunASR服务
双击 `funasr/启动FunASR服务.bat`

等待看到：
```
✅ 服务已启动！
   地址: http://127.0.0.1:10095
```

> ⚠ 首次运行会自动下载模型（约1GB），需等待5-10分钟

### 第2步：启动WPF主程序
双击 `IndustrialVoiceRecorder.WPF.exe`

或命令行：
```bash
cd src\IndustrialVoiceRecorder.WPF\bin\Debug\net8.0-windows
IndustrialVoiceRecorder.WPF.exe
```

## 五、蓝牙耳机配对

1. 打开Windows蓝牙设置
2. AirPods Pro放入充电盒，打开盖子，长按背面按钮至白灯闪烁
3. Windows中选择"添加蓝牙设备" → 选择"AirPods Pro"
4. 配对完成后，在程序中刷新设备列表即可

## 六、验证

1. FunASR服务窗口显示"服务已启动"
2. 程序状态栏显示"FunASR识别引擎已就绪"
3. 选择音频设备（AirPods Pro）

5. 等2-3秒后查看识别结果

## 七、常见问题

### Q: 程序提示"FunASR服务未启动"
- 确认已先启动 `启动FunASR服务.bat`
- 检查 `config.txt` 中的 Host 和 Port 是否正确
- 检查防火墙是否放行了端口

### Q: 首次启动FunASR很慢
- 首次需要下载模型（约1GB），请耐心等待
- 后续启动只需10-30秒

### Q: 识别结果为空
- 确保说话声音足够大（正常说话即可）
- 说完后等待2-3秒
- 检查Logs目录的日志文件排查

### Q: 另一台电脑部署FunASR
修改 `config.txt`：
```
FunASR.Host=192.168.1.100    ← 改为FunASR服务器的IP
FunASR.Port=10095
```
FunASR服务器端 `funasr_server.py` 中需要设置 `host="0.0.0.0"` 允许外部访问。
