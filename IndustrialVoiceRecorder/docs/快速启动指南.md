# 工业语音记录系统 - 快速启动指南

## 📋 系统要求

### 硬件要求
- **CPU**: Intel i5 第8代或以上（推荐i7）
- **内存**: 8GB 或以上
- **硬盘**: 至少2GB可用空间
- **蓝牙**: 蓝牙4.0+ 
- **推荐耳机**: AirPods Pro（已验证兼容）

### 软件要求
- **操作系统**: Windows 10 / Windows 11 (x64)
- **.NET运行时**: .NET 8.0 Runtime
- **蓝牙驱动**: Windows内置蓝牙驱动

---

## 🚀 安装步骤

### 第一步：安装.NET 8运行时
如果还未安装.NET 8运行时，请从微软官网下载安装：
https://dotnet.microsoft.com/download/dotnet/8.0

### 第二步：下载Whisper模型文件
1. 下载 `ggml-base.bin` 模型文件（约74MB）
   - 下载地址: https://huggingface.co/ggerganov/whisper.cpp/tree/main
   - 选择 `ggml-base.bin`
2. 将文件放入项目的 `Models/` 目录

### 第三步：构建项目
```bash
cd D:\Gemi\IndustrialVoiceRecorder\src
dotnet restore
dotnet build
```

### 第四步：运行程序
```bash
cd IndustrialVoiceRecorder.WPF
dotnet run
```

---

## 🎧 连接AirPods Pro

### 配对步骤
1. 打开Windows蓝牙设置（设置 → 蓝牙和设备）
2. 将AirPods Pro放入充电盒
3. 打开充电盒盖，长按背面按钮至白灯闪烁
4. 在Windows中点击"添加蓝牙设备"
5. 选择"AirPods Pro"进行配对
6. 等待连接成功

### 验证连接
1. 启动"工业语音记录系统"
2. 在设备下拉框中查看是否显示"AirPods Pro"或"Headset Microphone"
3. 如未显示，点击"🔄 刷新"按钮

## 📖 使用教程

### 基本操作流程

#### 1. 启动程序
双击运行程序，等待模型加载完成（首次约30秒）

#### 2. 选择设备
从设备下拉框选择AirPods Pro（程序会自动优先选择蓝牙设备）

#### 3. 设置操作员
在右上角输入操作员名称

#### 4. 开始录音
点击绿色 **"🎙 开始录音"** 按钮

#### 5. 语音输入
佩戴AirPods Pro，对着麦克风说出检测结果，例如：
- "1号产品OK"
- "2号产品表面划痕"
- "3号产品尺寸超差"
- "第4个NG，毛刺"

#### 6. 查看结果
- 实时识别文本会显示在蓝色区域
- 识别完成后自动生成结构化记录
- 记录会显示在下方表格中
- 底部统计栏实时更新

#### 7. 停止录音
点击红色 **"⏹ 停止录音"** 按钮

#### 8. 导出数据
点击 **"📊 导出Excel"** 按钮，文件保存在 `Export/` 目录

## 🗣️ 语音输入规范

### 推荐语音格式
```
[产品编号] + [检测结果] + [原因/备注]
```

### 示例
| 你说的话 | 系统解析 |
|---------|---------|
| "1号OK" | 产品1号，合格 |
| "2号NG划痕" | 产品2号，不合格，原因：划痕 |
| "第3个尺寸细小" | 产品3号，不合格，分类：尺寸 |
| "15号表面灰尘" | 产品15号，不合格，分类：外观 |
| "丝印偏移" | 不合格，分类：丝印 |

### 状态判定规则
- 包含以下词汇自动判定为 **NG**: 
  - NG、不合格、划痕、灰尘、毛刺、超差、损坏、变形、脱落、污渍、色差
- 未包含以上词汇默认为 **OK**

## ⚙️ 配置说明

### 模型选择
| 模型 | 大小 | 速度 | 准确率 | 推荐场景 |
|------|------|------|--------|---------|
| ggml-base.bin | 74MB | 快 | ~85% | 实时场景（推荐） |
| ggml-small.bin | 244MB | 中 | ~90% | 高精度需求 |
| ggml-medium.bin | 1.5GB | 慢 | ~95% | 最高精度（需高配PC） |

```
├── Logs/          # 日志文件
└── Models/        # Whisper模型文件
    └── ggml-base.bin  ← 请将模型文件放在这里
```

## ❓ 常见问题

### Q: 程序启动后提示"模型文件未找到"
**A**: 请确认已将 `ggml-base.bin` 文件放入 `Models/` 目录

### Q: 没有检测到音频设备
**A**: 
1. 检查AirPods Pro是否已配对连接
2. 打开Windows声音设置，确认蓝牙耳机已设为默认录音设备
3. 点击程序中的"🔄 刷新"按钮

### Q: 识别准确率不高
**A**:
1. 确保在安静环境使用
2. 说话时保持清晰、适中语速
3. 使用标准普通话
4. 可考虑升级为 `ggml-small.bin` 模型

### Q: 录音时没有识别结果
**A**:
1. 检查AirPods Pro麦克风是否正常
2. 在Windows声音设置中测试麦克风输入
3. 说话声音保持正常音量
4. 说完后等待1-2秒让系统识别

### Q: 程序运行缓慢
**A**:
1. 确认CPU满足最低要求（i5第8代+）
2. 使用 `ggml-base.bin` 模型（最快）
3. 关闭不必要的后台程序
4. 确保内存充足（8GB+）
